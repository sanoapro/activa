## Cómo están escritos los guiones

- **Un minuto de locución en español son unas 150 palabras.** Cada guion está medido para eso; si
  le agregas una frase, quita otra.
- Cada archivo trae **guion**, **escaleta con tiempos** y **notas de producción**.
- **Ninguno usa la palabra «comprar»**, ni precio, paquete, cotización o licencia. El video
  explica y provoca la pregunta; la conversación comercial ocurre después.
- Las cifras que aparecen salen del documento maestro. No se inventa ninguna.

## Antes de grabar

Revisa las notas de producción de cada guion: traen los límites de lo que se puede prometer.
En particular, el de `integra` marca qué módulos **no** se mencionan hasta que producto los
confirme por escrito.
